\# Activity 1 — C/C++ Development Environment Setup



\## Objective



Set up a C/C++ development environment using Visual Studio Code, the Microsoft C/C++ extension, and GCC through MSYS2/MinGW-w64.



\## Tools Used



\- Visual Studio Code

\- Microsoft C/C++ Extension

\- MSYS2/MinGW-w64

\- GCC

\- Windows PowerShell



\## What I Did



I configured Visual Studio Code for C/C++ development and installed the Microsoft C/C++ extension. I also configured the GCC compiler through MSYS2/MinGW-w64 and added the compiler path to the Windows PATH environment variable.



I created a C program named `hello.c`, compiled it using GCC, and executed the program successfully.
